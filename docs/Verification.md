- All admin screens; category/brand/product create, edit and deactivation.
- Add/increase/decrease/remove/clear cart and rejection of quantities above stock.
- Checkout success, stored price, cleared cart, exact stock decrement and duplicate-submit protection.
- Stale admin stock edit rejected after checkout; historical purchase price unaffected by a later price edit.
- Another customer's order returns 404.
- Pending cancellation restores stock once; repeated cancellation does not restore it again.
- Confirmed → Shipping → Completed transitions; Completed → Pending rejected.
- Dashboard successfully aggregates completed revenue.
- Valid PNG upload, GUID filename, serving image, rejection of a disguised script, and file removal.
- Two simultaneous buyers compete for one unit: exactly one successful order, stock stays zero, cancellation restores one.
- Deactivated customer loses existing authenticated access; reactivation permits login.
- Unknown page returns a friendly page with HTTP 404.

Test data is clearly labeled `Smoke` and `example.test`. Tests preserve order audit history and deactivate their catalog fixtures. An early test harness attempt used a missing CSRF token for a terminal-state order; the harness was corrected and the complete suite passed. No application bypass was added.
